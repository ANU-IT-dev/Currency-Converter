# Currency Converter 💱

A simple and responsive Currency Converter web application built using HTML, CSS, and JavaScript. It uses the Frankfurter API to fetch live exchange rates and supports multiple currencies.

## 🚀 Features

- Convert between multiple currencies
- Fetch live exchange rates using an API
- Dynamic currency dropdowns
- Country flags for selected currencies
- User-defined conversion amount
- Simple and responsive UI
- Error handling for failed API requests

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API

## 🔌 API Used

This project uses the **Frankfurter API** to fetch current exchange rates.
